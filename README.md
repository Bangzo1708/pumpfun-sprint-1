A deterministic TypeScript paper-trading bot for the pump.fun 24-hour replay: a filtered launch sniper with one pyramid add. It buys new coins only when they pass its launch filters, adds once into a winner, and exits on its take-profit / stop rules. Backtest on the official dev window: net PnL +0.1912 SOL across 124 coins, max drawdown 2.13%, guardrails passed.

## Run it

```sh
node main.ts
```
